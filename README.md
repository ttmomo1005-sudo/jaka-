# 派仔具身智能 · JAKA π 视觉模仿

让摄像头看到的人体动作，变成派仔机器人的关节目标，并连接网页三维展示与 MuJoCo 站立仿真。

这是项目的**轻量源码公开版**，用于展示关键实现、阶段成果和研究边界。保留视觉、关节映射、网页、站立策略适配与离线双臂保护代码；完整模型、运行环境和真机部署工程按需交流。

## 已完成的工作

- **人体姿态识别**：Google MediaPipe Pose 为主，YOLO Pose 为备用；将人体骨架映射为 27 维机器人关节目标。
- **双臂动作映射**：依据机器人 URDF 的实际关节轴和几何关系求解双臂姿态，结合置信度保持、平滑和限位。
- **网页交互**：摄像头骨架与机器人三维模型同步展示；独立保留关节拖拽页面，显示关节状态和链路耗时。
- **MuJoCo 站立仿真**：接入官方站立策略，由策略处理腿部支撑，上身目标经过速度和加速度限制；保留自由底座与重力。
- **离线双臂保护**：提供 8 个肩肘轴的 mock 控制链、轨迹限幅、超时处理和状态管理；公开代码没有真实电机写入后端。
- **早期安防视觉**：包含 YOLO 人体检测、方位与出现/丢失事件，以及人脸录入和识别核心代码。

## 做到哪一步

历史记录表明，项目已在真机上做过肩肘 8 轴跟随实验，腿部使用站立策略。连续真人动作跟随尚未完成完整验收；手指、腕、颈、腰不属于已验收的真机人体跟随能力，夹爪开合尚未实现。

同一组 **120 秒合成动作**的 MuJoCo 对照中，旧控制链发生 18 次复位（4 次倾倒、14 次漂移越界），新版为 0 次，最大水平位移约 5.19 cm。这是历史仿真测试记录，不能视为真人动作精度或真机稳定性验收；新版快速动作跟随滞后更大，静止场景也并非所有指标更优。详见 [仿真结果与边界](docs/SIMULATION_RESULTS.md)。
