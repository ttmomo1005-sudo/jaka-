# 项目说明

整理日期：2026-11-07。机器人平台为 JAKA π（派仔 / Khan_mini），27 个关节。

## 从视觉到机器人

电脑摄像头图像进入姿态识别服务，提取人体骨架，再转成机器人关节空间的 `robot_q`。网页显示相同的目标关节，MuJoCo 使用这些目标作为上身参考，经过轨迹限制后交给官方站立策略。网页中的目标姿态与物理仿真实际姿态有区别。

视觉主线使用 MediaPipe Pose Landmarker Heavy，具备 33 个关键点及 world 3D 输出；备用路径为 YOLO Pose。普通单目摄像头不能可靠恢复所有独立自由度，腕、颈等仍有近似。双臂使用机器人 URDF 的关节轴、偏移与阻尼最小二乘求解，腰部目标固定为零。

关节顺序：左腿 0–5、左臂 6–11、右腿 12–17、右臂 18–23、腰 24、颈 25–26。几何角 `geom_q` 用于人体角度解释，机器人空间 `robot_q` 用于模型与仿真；二者不能混用。

## 物理仿真

站立适配器以 50 Hz 更新。单帧观测 165 维，连续 10 帧堆成 1650 维输入，策略输出 27 维动作。上身参考限制为 2 rad/s、4 rad/s²，腰目标固定；策略负责腿部支撑。推理后不再直接把上身输出整段替换为摄像头角度。

上述限制作用于参考目标，不构成对实际电机速度的保证。自由底座、重力和并联踝约束保留；失稳复位被计入测试结果。

## 真机与公开代码的区别

2026-10-16 的现场记录确认连接过真机，并在专用模式下让肩肘 8 轴接收视觉目标，腿部由站立策略支撑。可跟随索引为 6、7、8、9、18、19、20、21。

完整连续跟随没有完成全部验收，夹爪控制尚未实现。本仓库的 `robot_bridge` 是电脑端离线准备与 mock，不是现场真机部署程序。公开版本没有硬件写入后端，也没有现场启停操作手册。

## 早期安防工作

人体检测模块使用 YOLO 检出 person，选择目标后输出水平偏移、方向，以及进入、跟踪、丢失事件，可供后续语音或决策模块消费。ROS 图像输入仍为占位。

人脸系统经历过 YOLOv8-Face + ArcFace 路径；当前选入源码的默认配置为 InsightFace 的 SCRFD 检测、关键点对齐和 ArcFace 特征，并保留 YOLO 相关实现。目录沿用历史名称。个人照片、身份名单和特征库均未公开。

历史语音工作验证过机器人中文播报；完整语音助手由协作方推进，不列作本公开版已经交付的功能。
